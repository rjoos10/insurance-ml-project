
# Insurance Cost Prediction with Machine Learning

This project explores machine learning methods to predict medical insurance costs based on demographic and health-related features. The goal is to understand how different variables influence insurance charges and to compare the performance of different regression models.

## Dataset

The dataset contains information such as age, BMI, smoking status, number of children, and region. The target variable is the insurance cost.

## Methods

The following steps are implemented:

 * Data exploration and visualization
 * Feature engineering 
 * Train/test split
 * Model training using:
  -Linear Regression
  -Random Forest
